# MasterDesk — рубеждік бақылау, ЛЗ 1–8

Репозиторий: https://github.com/zekochka/masterDesk

Бұл индекс қолдағы жобалық контекстке сүйеніп жасалған. ЛЗ 1–7 нақты GitHub файлдарының атаулары/жолдары осы сәтте тексерілмеді; қорғау алдында тиісті сілтемелерді өз репозиторийіңізден толтырыңыз. Жоқ файлды бар деп көрсетуге болмайды.

| Апта | Не көрсету керек | Репозиторийде тексеру |
|---|---|---|
| 1 | Құзырет картасы, қате аяқталған IT жоба талдауы | [ ] Құжат сілтемесі |
| 2 | ADR, техникалық шешімдер | [ ] docs/adr ішінен нақты файл |
| 3 | Charter, business case, бастапқы finmodel | [ ] Есеп пен .xlsx |
| 4 | Backlog/User Stories, Story Map, NFR | [ ] docs/requirements және GitHub board |
| 5 | WBS, release plan, RACI, capacity | [ ] docs/plan |
| 6 | Ықтималдық/бағалау есептері | [ ] notebooks/ және есеп |
| 7 | RAID/STRIDE, қауіпсіздік жоспары | [ ] docs/security және test status |
| 8 | SoW/SLA/SLO/бюджет | [x] docs/contract/sow.md; docs/ops/slo-sla.md; docs/lz8/ |

**Қорғау жоспары:** мәселе → MVP scope → архитектура → 260 тапсырыс/5 пайдаланушы бизнес-кейс → WBS/RACI → қауіп → SoW және қабылдау → үш SLO/SLA → 93,6 минут error budget → 12 ай OPEX 286 400 ₸ → 36 ай TCO және шешім.
