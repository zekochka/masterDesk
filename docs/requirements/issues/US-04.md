# US-04 — Құрылғы картасын жасау

**Epic:** Қабылдау  
**Priority:** P0  
**Size:** S  
**Release:** MVP  
**Owner (жоспар):** Амир  
**Depends on:** US-02

## User Story

Мен қабылдау қызметкері ретінде құрылғы түрі мен моделін жазуды қалаймын, сонда жөнделетін техниканы шатастырмауды.

## Қабылдау критерийлері (Given — When — Then)

- **Оң сценарий.** Берілген: қызметкер рөліне сай жүйеге кірген. Қашан: «құрылғы картасын жасау» әрекетін орындайды. Онда: түрі, моделі және ақау сипаттамасы енгізілсе, құрылғы клиентке байланыстырылып сақталады.
- **Теріс сценарий.** Берілген: дерек жарамсыз немесе құқық жеткіліксіз. Қашан: осы әрекетті орындауға тырысады. Онда: құрылғы түрі бос болса, жүйе жазбаны жасамайды.

## Дайындық шарты

API/UI сценарийі көрсетілген, рөлдік құқық тексерілген, қате жағдайда дерек бүлінбеген, өзгеріс GitHub PR арқылы тексерілген.
