# US-19 — Ескі тізімнен деректерді импорттау

**Epic:** Бақылау  
**Priority:** P1  
**Size:** M  
**Release:** Кейінгі кезең  
**Owner (жоспар):** Ханкелді  
**Depends on:** US-02, US-05

## User Story

Мен әкімші ретінде клиенттер мен тапсырыстарды CSV-ден көшіруді қалаймын, сонда жүйеге көшуді жеңілдетуді.

## Қабылдау критерийлері (Given — When — Then)

- **Оң сценарий.** Берілген: қызметкер рөліне сай жүйеге кірген. Қашан: «ескі тізімнен деректерді импорттау» әрекетін орындайды. Онда: дұрыс CSV бағандары алдын ала тексеріліп, импорт қорытындысы көрсетіледі.
- **Теріс сценарий.** Берілген: дерек жарамсыз немесе құқық жеткіліксіз. Қашан: осы әрекетті орындауға тырысады. Онда: қайталанған немесе қате жолдар бөлек есептеліп, импорт үнсіз қабылданбайды.

## Дайындық шарты

API/UI сценарийі көрсетілген, рөлдік құқық тексерілген, қате жағдайда дерек бүлінбеген, өзгеріс GitHub PR арқылы тексерілген.
