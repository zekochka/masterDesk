# US-08 — Диагностика қорытындысын енгізу

**Epic:** Диагностика  
**Priority:** P0  
**Size:** M  
**Release:** MVP  
**Owner (жоспар):** Ханкелді  
**Depends on:** US-07

## User Story

Мен шебер ретінде ақау мен диагностика нәтижесін жазуды қалаймын, сонда жөндеу себебін кейін көруді.

## Қабылдау критерийлері (Given — When — Then)

- **Оң сценарий.** Берілген: қызметкер рөліне сай жүйеге кірген. Қашан: «диагностика қорытындысын енгізу» әрекетін орындайды. Онда: рұқсаты бар шебер диагноз жазса, жазба тапсырысқа сақталады.
- **Теріс сценарий.** Берілген: дерек жарамсыз немесе құқық жеткіліксіз. Қашан: осы әрекетті орындауға тырысады. Онда: басқа тапсырысқа құқықсыз шебер енгізген өзгеріс қабылданбайды.

## Дайындық шарты

API/UI сценарийі көрсетілген, рөлдік құқық тексерілген, қате жағдайда дерек бүлінбеген, өзгеріс GitHub PR арқылы тексерілген.
