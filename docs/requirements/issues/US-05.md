# US-05 — Жөндеу тапсырысын ашу

**Epic:** Қабылдау  
**Priority:** P0  
**Size:** M  
**Release:** MVP  
**Owner (жоспар):** Ханкелді  
**Depends on:** US-02, US-04

## User Story

Мен қабылдау қызметкері ретінде клиент пен құрылғыға жөндеу тапсырысын ашуды қалаймын, сонда өтінімді тіркелген нөмір арқылы бақылауды.

## Қабылдау критерийлері (Given — When — Then)

- **Оң сценарий.** Берілген: қызметкер рөліне сай жүйеге кірген. Қашан: «жөндеу тапсырысын ашу» әрекетін орындайды. Онда: клиент пен құрылғы таңдалса, бірегей нөмірі бар «Қабылданды» тапсырысы құрылады.
- **Теріс сценарий.** Берілген: дерек жарамсыз немесе құқық жеткіліксіз. Қашан: осы әрекетті орындауға тырысады. Онда: басқа клиентке тиесілі құрылғы таңдалса, тапсырыс сақталмайды.

## Дайындық шарты

API/UI сценарийі көрсетілген, рөлдік құқық тексерілген, қате жағдайда дерек бүлінбеген, өзгеріс GitHub PR арқылы тексерілген.
