# US-06 — Тапсырыстар тізімін көру

**Epic:** Жоспарлау  
**Priority:** P0  
**Size:** S  
**Release:** MVP  
**Owner (жоспар):** Амир  
**Depends on:** US-05

## User Story

Мен әкімші ретінде барлық қолжетімді тапсырыстар тізімін қарауды қалаймын, сонда күнделікті ағынды басқаруды.

## Қабылдау критерийлері (Given — When — Then)

- **Оң сценарий.** Берілген: қызметкер рөліне сай жүйеге кірген. Қашан: «тапсырыстар тізімін көру» әрекетін орындайды. Онда: тізімде тапсырыс нөмірі, құрылғы, статус және жауапты шебер көрінеді.
- **Теріс сценарий.** Берілген: дерек жарамсыз немесе құқық жеткіліксіз. Қашан: осы әрекетті орындауға тырысады. Онда: рұқсаты жоқ қызметкер өз құзыретіне кірмейтін деректерді көрмейді.

## Дайындық шарты

API/UI сценарийі көрсетілген, рөлдік құқық тексерілген, қате жағдайда дерек бүлінбеген, өзгеріс GitHub PR арқылы тексерілген.
