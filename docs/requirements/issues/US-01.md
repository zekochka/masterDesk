# US-01 — Қызметкердің жүйеге кіруі

**Epic:** Қабылдау  
**Priority:** P0  
**Size:** S  
**Release:** MVP  
**Owner (жоспар):** Ханкелді  
**Depends on:** —

## User Story

Мен қызметкер ретінде жеке логинім арқылы жүйеге кіруді қалаймын, сонда өз рөліме сәйкес жұмыс істеуді.

## Қабылдау критерийлері (Given — When — Then)

- **Оң сценарий.** Берілген: қызметкер рөліне сай жүйеге кірген. Қашан: «қызметкердің жүйеге кіруі» әрекетін орындайды. Онда: дұрыс логин мен пароль енгізілсе, жүйе пайдаланушының рөліне сай бетті ашады.
- **Теріс сценарий.** Берілген: дерек жарамсыз немесе құқық жеткіліксіз. Қашан: осы әрекетті орындауға тырысады. Онда: қате пароль енгізілсе, жүйе кіруге рұқсат бермейді және қатені түсіндіреді.

## Дайындық шарты

API/UI сценарийі көрсетілген, рөлдік құқық тексерілген, қате жағдайда дерек бүлінбеген, өзгеріс GitHub PR арқылы тексерілген.
