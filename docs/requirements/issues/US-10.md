# US-10 — Бағаның келісілгенін белгілеу

**Epic:** Диагностика  
**Priority:** P0  
**Size:** M  
**Release:** MVP  
**Owner (жоспар):** Ханкелді  
**Depends on:** US-09

## User Story

Мен әкімші ретінде бағаға клиент келісімін тіркеуді қалаймын, сонда рұқсатсыз жөндеуге өтпеуді.

## Қабылдау критерийлері (Given — When — Then)

- **Оң сценарий.** Берілген: қызметкер рөліне сай жүйеге кірген. Қашан: «бағаның келісілгенін белгілеу» әрекетін орындайды. Онда: баға бекітілгенде, келісім статусы, күн және қызметкер сақталады.
- **Теріс сценарий.** Берілген: дерек жарамсыз немесе құқық жеткіліксіз. Қашан: осы әрекетті орындауға тырысады. Онда: келісімсіз тапсырысты «Жөнделуде» күйіне өткізу бұғатталады.

## Дайындық шарты

API/UI сценарийі көрсетілген, рөлдік құқық тексерілген, қате жағдайда дерек бүлінбеген, өзгеріс GitHub PR арқылы тексерілген.
