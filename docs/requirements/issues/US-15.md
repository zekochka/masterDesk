# US-15 — Нөмір және статус бойынша іздеу

**Epic:** Бақылау  
**Priority:** P0  
**Size:** M  
**Release:** MVP  
**Owner (жоспар):** Амир  
**Depends on:** US-06

## User Story

Мен әкімші ретінде тапсырысты нөмірі, статусымен немесе шеберімен табуды қалаймын, сонда клиентке тез жауап беруді.

## Қабылдау критерийлері (Given — When — Then)

- **Оң сценарий.** Берілген: қызметкер рөліне сай жүйеге кірген. Қашан: «нөмір және статус бойынша іздеу» әрекетін орындайды. Онда: белгілі нөмір бойынша іздегенде тек сәйкес тапсырыс шығады.
- **Теріс сценарий.** Берілген: дерек жарамсыз немесе құқық жеткіліксіз. Қашан: осы әрекетті орындауға тырысады. Онда: сәйкес жазба болмаса, жүйе қате дерек көрсетпей, бос нәтиже береді.

## Дайындық шарты

API/UI сценарийі көрсетілген, рөлдік құқық тексерілген, қате жағдайда дерек бүлінбеген, өзгеріс GitHub PR арқылы тексерілген.
