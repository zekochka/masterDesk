# US-17 — Рөлдерге сай қолжетімділік

**Epic:** Бақылау  
**Priority:** P0  
**Size:** M  
**Release:** MVP  
**Owner (жоспар):** Ханкелді  
**Depends on:** US-01

## User Story

Мен басшы ретінде қызметкерге рөл бойынша құқық беруді қалаймын, сонда клиент деректерін қорғалмаған қолжетімділіктен сақтауды.

## Қабылдау критерийлері (Given — When — Then)

- **Оң сценарий.** Берілген: қызметкер рөліне сай жүйеге кірген. Қашан: «рөлдерге сай қолжетімділік» әрекетін орындайды. Онда: әкімші, қабылдау қызметкері, шебер және басшыға рұқсат деңгейлері қолданылады.
- **Теріс сценарий.** Берілген: дерек жарамсыз немесе құқық жеткіліксіз. Қашан: осы әрекетті орындауға тырысады. Онда: шеберге ғана арналған рөл арқылы басқа қызметкер әкімшілік операция жасай алмайды.

## Дайындық шарты

API/UI сценарийі көрсетілген, рөлдік құқық тексерілген, қате жағдайда дерек бүлінбеген, өзгеріс GitHub PR арқылы тексерілген.
