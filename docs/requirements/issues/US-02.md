# US-02 — Жаңа клиентті тіркеу

**Epic:** Қабылдау  
**Priority:** P0  
**Size:** S  
**Release:** MVP  
**Owner (жоспар):** Амир  
**Depends on:** US-01

## User Story

Мен қабылдау қызметкері ретінде клиенттің аты мен байланыс нөмірін тіркеуді қалаймын, сонда тапсырысты нақты адаммен байланыстыруды.

## Қабылдау критерийлері (Given — When — Then)

- **Оң сценарий.** Берілген: қызметкер рөліне сай жүйеге кірген. Қашан: «жаңа клиентті тіркеу» әрекетін орындайды. Онда: міндетті өрістер толтырылса, клиент картасы жасалады.
- **Теріс сценарий.** Берілген: дерек жарамсыз немесе құқық жеткіліксіз. Қашан: осы әрекетті орындауға тырысады. Онда: байланыс нөмірі міндетті форматқа сәйкес келмесе, сақтау бұғатталады.

## Дайындық шарты

API/UI сценарийі көрсетілген, рөлдік құқық тексерілген, қате жағдайда дерек бүлінбеген, өзгеріс GitHub PR арқылы тексерілген.
