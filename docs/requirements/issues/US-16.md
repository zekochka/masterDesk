# US-16 — Өзгерістер тарихын қарау

**Epic:** Бақылау  
**Priority:** P0  
**Size:** M  
**Release:** MVP  
**Owner (жоспар):** Ханкелді  
**Depends on:** US-11

## User Story

Мен басшы ретінде тапсырыстағы маңызды өзгерістерді қарауды қалаймын, сонда кім және қашан өзгерткенін тексеруді.

## Қабылдау критерийлері (Given — When — Then)

- **Оң сценарий.** Берілген: қызметкер рөліне сай жүйеге кірген. Қашан: «өзгерістер тарихын қарау» әрекетін орындайды. Онда: статус пен шебер өзгерген кезде авторы, уақыты және ескі/жаңа мәндер жазылады.
- **Теріс сценарий.** Берілген: дерек жарамсыз немесе құқық жеткіліксіз. Қашан: осы әрекетті орындауға тырысады. Онда: қарапайым қызметкер журнал жазбасын өзгерте немесе өшіре алмайды.

## Дайындық шарты

API/UI сценарийі көрсетілген, рөлдік құқық тексерілген, қате жағдайда дерек бүлінбеген, өзгеріс GitHub PR арқылы тексерілген.
