# US-09 — Алдын ала жөндеу бағасын көрсету

**Epic:** Диагностика  
**Priority:** P0  
**Size:** S  
**Release:** MVP  
**Owner (жоспар):** Ханкелді  
**Depends on:** US-08

## User Story

Мен шебер ретінде жөндеу бағасын көрсетуді қалаймын, сонда клиентпен келісетін соманы нақтылауды.

## Қабылдау критерийлері (Given — When — Then)

- **Оң сценарий.** Берілген: қызметкер рөліне сай жүйеге кірген. Қашан: «алдын ала жөндеу бағасын көрсету» әрекетін орындайды. Онда: теріс емес бүтін теңге сомасы енгізілсе, бағасы тапсырысқа тіркеледі.
- **Теріс сценарий.** Берілген: дерек жарамсыз немесе құқық жеткіліксіз. Қашан: осы әрекетті орындауға тырысады. Онда: теріс сома немесе дұрыс емес сан қабылданбайды.

## Дайындық шарты

API/UI сценарийі көрсетілген, рөлдік құқық тексерілген, қате жағдайда дерек бүлінбеген, өзгеріс GitHub PR арқылы тексерілген.
