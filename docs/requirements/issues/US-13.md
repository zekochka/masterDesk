# US-13 — Беруге дайын деп белгілеу

**Epic:** Беру  
**Priority:** P0  
**Size:** S  
**Release:** MVP  
**Owner (жоспар):** Амир  
**Depends on:** US-11

## User Story

Мен шебер ретінде жөнделген құрылғыны беруге дайын деп белгілеуді қалаймын, сонда қабылдау қызметкеріне сигнал беруді.

## Қабылдау критерийлері (Given — When — Then)

- **Оң сценарий.** Берілген: қызметкер рөліне сай жүйеге кірген. Қашан: «беруге дайын деп белгілеу» әрекетін орындайды. Онда: жөндеу кезеңі аяқталса, тапсырыс «Беруге дайын» статусына өтеді.
- **Теріс сценарий.** Берілген: дерек жарамсыз немесе құқық жеткіліксіз. Қашан: осы әрекетті орындауға тырысады. Онда: рұқсатсыз пайдаланушы дайындық статусын өзгерте алмайды.

## Дайындық шарты

API/UI сценарийі көрсетілген, рөлдік құқық тексерілген, қате жағдайда дерек бүлінбеген, өзгеріс GitHub PR арқылы тексерілген.
