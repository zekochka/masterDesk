# US-20 — Тапсырыс тізімін экспорттау

**Epic:** Бақылау  
**Priority:** P1  
**Size:** S  
**Release:** Кейінгі кезең  
**Owner (жоспар):** Амир  
**Depends on:** US-06

## User Story

Мен басшы ретінде рұқсат етілген деректерді CSV-ге шығаруды қалаймын, сонда есеп дайындауды және дерекке тәуелділікті азайтуды.

## Қабылдау критерийлері (Given — When — Then)

- **Оң сценарий.** Берілген: қызметкер рөліне сай жүйеге кірген. Қашан: «тапсырыс тізімін экспорттау» әрекетін орындайды. Онда: таңдалған сүзгідегі деректер CSV ретінде сақталады.
- **Теріс сценарий.** Берілген: дерек жарамсыз немесе құқық жеткіліксіз. Қашан: осы әрекетті орындауға тырысады. Онда: рұқсатсыз қызметкер экспорттау батырмасын да, API әрекетін де пайдалана алмайды.

## Дайындық шарты

API/UI сценарийі көрсетілген, рөлдік құқық тексерілген, қате жағдайда дерек бүлінбеген, өзгеріс GitHub PR арқылы тексерілген.
