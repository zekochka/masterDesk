# US-03 — Бар клиентті телефонмен табу

**Epic:** Қабылдау  
**Priority:** P0  
**Size:** S  
**Release:** MVP  
**Owner (жоспар):** Амир  
**Depends on:** US-02

## User Story

Мен қабылдау қызметкері ретінде клиентті телефон нөмірімен табуды қалаймын, сонда бір клиентке қайталанатын карта ашпауды.

## Қабылдау критерийлері (Given — When — Then)

- **Оң сценарий.** Берілген: қызметкер рөліне сай жүйеге кірген. Қашан: «бар клиентті телефонмен табу» әрекетін орындайды. Онда: бұрын тіркелген телефон енгізілсе, тиісті клиент картасы ашылады.
- **Теріс сценарий.** Берілген: дерек жарамсыз немесе құқық жеткіліксіз. Қашан: осы әрекетті орындауға тырысады. Онда: сәйкестік жоқ болса, жүйе бос нәтижені көрсетіп, жалған клиент жасамайды.

## Дайындық шарты

API/UI сценарийі көрсетілген, рөлдік құқық тексерілген, қате жағдайда дерек бүлінбеген, өзгеріс GitHub PR арқылы тексерілген.
