# US-18 — Тапсырыстардың жиынтық көрсеткіші

**Epic:** Бақылау  
**Priority:** P1  
**Size:** S  
**Release:** Кейінгі кезең  
**Owner (жоспар):** Амир  
**Depends on:** US-06

## User Story

Мен басшы ретінде аяқталған және белсенді тапсырыс санын көруді қалаймын, сонда жұмыс жүктемесін бағалауды.

## Қабылдау критерийлері (Given — When — Then)

- **Оң сценарий.** Берілген: қызметкер рөліне сай жүйеге кірген. Қашан: «тапсырыстардың жиынтық көрсеткіші» әрекетін орындайды. Онда: таңдалған кезең бойынша екі көрсеткіш есептеледі.
- **Теріс сценарий.** Берілген: дерек жарамсыз немесе құқық жеткіліксіз. Қашан: осы әрекетті орындауға тырысады. Онда: күн аралығы қате болса, жүйе дұрыс түсіндірме береді.

## Дайындық шарты

API/UI сценарийі көрсетілген, рөлдік құқық тексерілген, қате жағдайда дерек бүлінбеген, өзгеріс GitHub PR арқылы тексерілген.
