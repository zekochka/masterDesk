# US-12 — Жөндеу жазбасын толықтыру

**Epic:** Жөндеу  
**Priority:** P1  
**Size:** S  
**Release:** Кейінгі кезең  
**Owner (жоспар):** Ханкелді  
**Depends on:** US-11

## User Story

Мен шебер ретінде жұмыс сипаттамасын тапсырысқа тіркеуді қалаймын, сонда атқарылған жөндеуді жоғалтпауды.

## Қабылдау критерийлері (Given — When — Then)

- **Оң сценарий.** Берілген: қызметкер рөліне сай жүйеге кірген. Қашан: «жөндеу жазбасын толықтыру» әрекетін орындайды. Онда: жөндеу барысы бойынша түсініктеме тапсырыс тарихына қосылады.
- **Теріс сценарий.** Берілген: дерек жарамсыз немесе құқық жеткіліксіз. Қашан: осы әрекетті орындауға тырысады. Онда: бос мазмұнды жазба сақталмайды.

## Дайындық шарты

API/UI сценарийі көрсетілген, рөлдік құқық тексерілген, қате жағдайда дерек бүлінбеген, өзгеріс GitHub PR арқылы тексерілген.
