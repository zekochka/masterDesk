# US-07 — Шеберді тағайындау

**Epic:** Жоспарлау  
**Priority:** P0  
**Size:** S  
**Release:** MVP  
**Owner (жоспар):** Ханкелді  
**Depends on:** US-05

## User Story

Мен әкімші ретінде тапсырысқа жауапты шебер таңдауды қалаймын, сонда жұмыстың иесін анық көрсетуді.

## Қабылдау критерийлері (Given — When — Then)

- **Оң сценарий.** Берілген: қызметкер рөліне сай жүйеге кірген. Қашан: «шеберді тағайындау» әрекетін орындайды. Онда: белсенді шебер таңдалса, тапсырыста оның аты сақталады.
- **Теріс сценарий.** Берілген: дерек жарамсыз немесе құқық жеткіліксіз. Қашан: осы әрекетті орындауға тырысады. Онда: белсенді емес қызметкер шебер ретінде тағайындалмайды.

## Дайындық шарты

API/UI сценарийі көрсетілген, рөлдік құқық тексерілген, қате жағдайда дерек бүлінбеген, өзгеріс GitHub PR арқылы тексерілген.
