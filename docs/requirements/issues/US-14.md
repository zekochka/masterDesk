# US-14 — Құрылғыны клиентке беруді тіркеу

**Epic:** Беру  
**Priority:** P0  
**Size:** S  
**Release:** MVP  
**Owner (жоспар):** Ханкелді  
**Depends on:** US-13

## User Story

Мен қабылдау қызметкері ретінде құрылғы берілгенін рәсімдеуді қалаймын, сонда тапсырысты толық жабуды.

## Қабылдау критерийлері (Given — When — Then)

- **Оң сценарий.** Берілген: қызметкер рөліне сай жүйеге кірген. Қашан: «құрылғыны клиентке беруді тіркеу» әрекетін орындайды. Онда: «Беруге дайын» тапсырысында берілген күні тіркеліп, статус «Клиентке берілді» болады.
- **Теріс сценарий.** Берілген: дерек жарамсыз немесе құқық жеткіліксіз. Қашан: осы әрекетті орындауға тырысады. Онда: беруге дайын емес тапсырысты жабуға жүйе рұқсат етпейді.

## Дайындық шарты

API/UI сценарийі көрсетілген, рөлдік құқық тексерілген, қате жағдайда дерек бүлінбеген, өзгеріс GitHub PR арқылы тексерілген.
