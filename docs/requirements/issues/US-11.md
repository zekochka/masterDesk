# US-11 — Тапсырыс статусын өзгерту

**Epic:** Жөндеу  
**Priority:** P0  
**Size:** M  
**Release:** MVP  
**Owner (жоспар):** Ханкелді  
**Depends on:** US-10

## User Story

Мен шебер ретінде жөндеу статусын кезең-кезеңімен жаңартуды қалаймын, сонда әр тапсырыстың ағымдағы жағдайын білуді.

## Қабылдау критерийлері (Given — When — Then)

- **Оң сценарий.** Берілген: қызметкер рөліне сай жүйеге кірген. Қашан: «тапсырыс статусын өзгерту» әрекетін орындайды. Онда: рұқсат етілген ауысуда жаңа статус пен уақыт сақталады.
- **Теріс сценарий.** Берілген: дерек жарамсыз немесе құқық жеткіліксіз. Қашан: осы әрекетті орындауға тырысады. Онда: «Қабылданды» статусынан бірден «Клиентке берілді» ауысуына жүйе рұқсат етпейді.

## Дайындық шарты

API/UI сценарийі көрсетілген, рөлдік құқық тексерілген, қате жағдайда дерек бүлінбеген, өзгеріс GitHub PR арқылы тексерілген.
