# Коммуникация жоспары

> **Мәртебе:** 20.10.2026 күнгі TechPoint үшін ұсынылған талаптардың жұмыс нұсқасы; ресми бекіту күтіледі.

| Тақырып | Кімге | Жиілік | Канал | Иесі | Нәтиже |
| --- | --- | --- | --- | --- | --- |
| MVP құрамы, басымдық, ашық шешім | Байкенов Оспан / уәкілетті өкіл | Аптасына 1 рет, 20 мин | Алдын ала күн тәртібі + кездесу/қоңырау | Амир | Шешім журналына қорытынды |
| Сценарий мен өрістерді тексеру | Қабылдау қызметкері, шебер | Әр 2 аптада, 30 мин | Демо + 5–10 нақты жағдайды қарау | Амир | Талапқа өзгеріс Issue-ге түседі |
| Тапсырмалар, бөгеттер, API келісімі | Амир және Ханкелді | Аптасына 2 рет, 15 мин | GitHub Projects + қысқа қоңырау | Амир | Әр тапсырмада owner/size |

| Көлем, мерзім, құндағы өзгеріс | TechPoint өкілі | Триггер: >1 апта кешігу не >15% смета | Жазбаша хабарлама + нұсқалар | Амир | Рұқсатсыз көлем өспейді |

## Жұмыс сұрақтарын жинау тәртібі

1. Барлық сұрақ `docs/requirements/open-questions.md` және тиісті GitHub Issue ішінде жиналады: контекст, шешім нұсқалары, жауаптың соңғы күні, жауапты адам.
2. Амир апталық кездесуден кемінде 1 күн бұрын бір тізім жібереді, мәселе сайын бөлек хабарлама жіберілмейді.
3. 24 сағат ішінде шешім керек қауіпсіздік қатесі ғана жеке жедел хабарланады. Қалғаны апталық күн тәртібіне қосылады.
4. Расталған шешімнен кейінгі өзгеріс тиісті User Story мен NFR сілтемелерінде бейнеленеді. Келісу болмаған кезде талап «ұсыныс» күйінде қалады.
