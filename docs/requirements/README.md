# MasterDesk — талаптар пакеті (ЛЗ 4)

> **Мәртебе:** 20.10.2026 күнгі TechPoint үшін ұсынылған талаптардың жұмыс нұсқасы; ресми бекіту күтіледі.

## Құжаттар

| Файл | Мақсаты |
|---|---|
| `stakeholders.md` | ықпал / қызығушылық матрицасы |
| `communications.md` | коммуникация ережелері |
| `interviews.md` | екі сценарий және backlog-қа ұсынылатын өзгерістер |
| `story-map.png/.svg/.excalidraw` | storyboard кескіні және өңделетін нұсқалары |
| `story-map.md` | Story Map мәтіндік сипаттамасы |
| `mvp-scope.md` | сквозной MVP және кейінгі ауқым |
| `backlog.md` / `backlog.csv` | 20 story жиынтық кестесі |
| `issues/US-XX.md` | әр story-дің толық қабылдау критерийлері |
| `nfr.md` | 16 өлшенетін НФТ |
| `traceability.md` | ЛЗ 3, US, NFR арасындағы байланыс |
| `open-questions.md` | кейін тексерілетін сұрақтар |
| `lz4-acceptance-checklist.md` | тапсырма бойынша дайындық пен ашық қадамдар |

## Репозиторийде жасау керек

GitHub Issues — осы құжаттамамен бөлек объект. `scripts/publish_lz4_issues.py` скрипті `gh` CLI арқылы Issue-лерді жариялауға арналған, алдымен құрғақ тексеру режимінде іске қосылады. Қалғаны `README_LZ4_PUSH.txt` файлына жазылған.
