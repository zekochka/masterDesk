## Математика

```
сағаттық құн = 300000 / 168 * 1.12 = 2000 ₸
толық жылдағы пайдалы уақыт құны = (18 - мақсат_мин) * 260 / 60 * 2000 * 0.8 * 12
TCO(3y) = бастапқы шығын + 3 * жылдық шығын
ROI(3y) = (3 жылдық пайда - TCO) / TCO
NPV = - бастапқы шығын + Σ[(жылдық пайда_t - жылдық шығын_t)/(1+0.15)^t]
```

Пайда еңбекақы бюджетінің тікелей үнемделуі емес: уақыттың босауынан алынуы *ықтимал* экономикалық әсер. Нақты ақша үнемделуі үшін артық сағаттарды/қосымша тапсырыстарды айналымға айналдыру дәлелденуі тиіс.
