# Команда топологиясы және RACI

**Stream-aligned:** MasterDesk-тің өнім ағыны — Амир (PM/Angular) және Ханкелді (.NET/PostgreSQL); жеке бөлімдер жоқ. **Platform:** сыртқы хостинг / TechPoint IT (болуы және қолжетімділігі расталады); команда ішінде орта мен CI баптауы өз күшімізбен. **Enabling:** TechPoint өкілі мен тәжірибелі қызметкердің жұмыс процесін түсіндіруі (әзірге жоспарланған қолдау).

R — орындайды, A — нәтиженің қабылдануына жауапты, C — кеңес береді, I — ақпарат алады. A/R бір адамға қатар берілуі мүмкін.

| Артефакт / шешім | Амир | Ханкелді | TechPoint өкілі |
|---|---|---|---|
| Backlog және инкремент жоспары | A/R | C | C |
| API келісімшарты | A/R | C | I |
| PostgreSQL схемасы | C | A/R | I |
| Backend API және құқықтар | C | A/R | I |
| Angular экрандары | A/R | C | I |
| GitHub CI | A/R | C | I |
| End-to-end тексеру хаттамасы | C | A/R | I |
| CSV көшіру үлгісі | C | A/R | I |
| Пайдаланушы нұсқаулығы мен оқу демосы | A/R | C | I |
| Тест ортасын тапсыру пакеті | C | A/R | I |
| TechPoint талаптары туралы ресми шешім | C | C | A/R* |

\* TechPoint жағындағы өкілетті адам және шешім қабылдау құқығы **нақтылануы қажет**; бұл RACI — жоспарлық ұсыныс, ресми қабылдау дәлелі емес. Әр жолда **бір ғана A** белгіленген.
