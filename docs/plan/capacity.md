# MasterDesk — №5 зертханалық жұмыс құжаттары

TechPoint сервис орталығына арналған жоспар. Команда: Амир (PM / Angular), Жандарбек Ханкелді (.NET / PostgreSQL).

> **Мәртебе:** оқу жобасына арналған болжамды жоспар. TechPoint-пен сұхбат, мерзім және ресми қабылдау әлі расталмаған. Кестедегі күндер — ұсынылатын бақылау мерзімдері.

ЛЗ 3-тегі бағалау: 290 сағат × 2 500 ₸ = 725 000 ₸ еңбек құны; қосымша деректер көшіру 50 000 ₸, оқыту 35 000 ₸ және ескі тәсілден шығу 15 000 ₸ — жиыны 825 000 ₸. Бұлар нақты шарт емес.

## Файлдар
- `wbs.md` — үш деңгейлі WBS, сағат есебі, бес пакет сөздігі.
- `release-plan.md` — үш инкремент, вехалар, критерийлер және scope қысқарту.
- `dependencies.md` — Mermaid диаграммасы және төрт сыртқы тәуелділік.
- `raci.md` — команда топологиясы және бір ғана `A` белгісі бар RACI.
- `capacity.md` — команда жүктемесінің есебі.
- `reminders.ics` — сыртқы растау мерзімдеріне дейін 3 күн бұрын ескертетін күнтізбе жазбалары.

GitHub-тағы бұрынғы Issues / User Stories сақталады. Осы жоспармен салыстыру кейінгі тексеріс ретінде қаралады.
