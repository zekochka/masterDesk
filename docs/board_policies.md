# Тапсырмалар ағынын басқару регламенті (Flow & Board Policies) — MasterDesk

## 1. Аяқталмаған жұмыс лимиттері (WIP Limits)
- **In Progress (Орындалуда):** бір орындаушыға бір уақытта ең көбі 2 тапсырма.
- **Review (Код-ревью және тексеру):** бүкіл команда бойынша жиынтығы ең көбі 3 тапсырма.
- **Blocked (Бұғатталған):** тапсырма осы бағанға түскенде, орындаушы дереу бұғатталудың ішкі немесе сыртқы себебін көрсетіп, командаға хабарлауға міндетті.

---

## 2. Жұмысқа дайындық критерийлері (Definition of Ready — DoR)
Тапсырма тек келесі шарттар орындалғанда ғана `Backlog` бағанынан `Ready` (спринтке дайын) күйіне ауыстырылуы мүмкін:
1. Пайдаланушы оқиғасы пішімінде тұжырымдалған: *«[Рөл] ретінде, мен [құндылыққа] қол жеткізу үшін [әрекетті] орындағым келеді»*.
2. `Given — When — Then` (Берілгені — Егер — Онда) пішімінде нақты қабылдау критерийлері бар (кемінде 1 негатив сценарийді қоса алғанда).
3. Көлемі бойынша бағаланған (S / M). **L** көлеміндегі тапсырмалар декомпозицияланады (бөлінеді) — L тапсырмаларын спринтке алуға тыйым салынады.
4. Сыртқы және жүйелік тәуелділіктер (егер бар болса) анықталып, тіркелген.

---

## 3. Аяқталу критерийлері (Definition of Done — DoD)
Тапсырма барлық шарттар орындалғанда ғана жабылды (`Done`) деп есептеледі:
1. Код жазылған, команданың қабылданған келісімдері бойынша рәсімделген және модульдік/интеграциялық тестілермен қамтылған.
2. Pull Request құрылған, CI-тексерулері сәтті өткен (пайплайн «жасыл»).
3. Команданың кемінде бір мүшесі код-ревью жүргізіп, растау алынған (Approved).
4. Функционал стендте орналастырылып, тестіленген (өтпелі/сквозной сценарий тексерілген).
5. Қажет болған жағдайда құжаттама жаңартылған (API, пайдаланушы нұсқаулығы немесе сұлбалар).

---

## 4. Тақта бағандарына кіру және шығу саясаттары (Entry & Exit Policies)

| Баған | Кіру саясаты (Entry Criteria) | Шығу саясаты (Exit Criteria) |
| :--- | :--- | :--- |
| **Backlog** | Идея/талап трекерге бастапқы сипаттамасымен енгізілген. | Тапсырма **DoR** талаптарына сәйкестендірілген, басымдығы таңдалған. |
| **Ready** | DoR барлық шарттары орындалған; тапсырма спринтте іске асыру үшін таңдалған. | Орындаушы тапсырманы жұмысқа алды (WIP-лимитін сақтай отырып). |
| **In Progress** | Орындаушы тағайындалған (Owner), мәртебесі өзгертілген, бұтақ (ветка) ереже бойынша құрылған (`feat/ABC-12-name`). | Іске асыру жергілікті ортада аяқталған, тестілер жазылған, Pull Request ашылған. |
| **Review** | PR ашылған, автотестілер өткен, тексеруші тағайындалған. Бағанда жиынтығы 3-тен аспайтын тапсырма бар. | Ревьюерден Approve алынған, бұтақ `main`-ге қосылған (merge жасалған). |
| **Blocked** | Блокер туындаған (техникалық ақау, рұқсатты күту, сыртқы тәуелділік). Себебі көрсетілген түсініктеме (комментарий) жазылған. | Кедергі жойылған, тапсырма бастапқы мәртебесіне қайтарылған. |
| **Done** | **DoD** барлық тармақтары толық орындалған. | Тапсырма спринт демосында көрсетілген және жабылған. |
