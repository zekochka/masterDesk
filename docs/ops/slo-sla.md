# MasterDesk — SLI / SLO / SLA және error budget (ЛЗ 8)

**Күйі:** жоспарлық, қолданыстағы SLA емес; 20.10.2026. Өлшеу: UI Save/Іздеу басылғаннан нәтижені көргенге дейін, audit журналы мен API логтарын қоса есептеу.

| Сценарий | Айлық көлем (болжам) | SLO (ішкі) | SLA (ұсыныс, жұмсағырақ) |
|---|---:|---|---|
| Жөндеу тапсырысын сақтау (UI-та ID) | 260 | ≥99% ≤2 сек | ≥98,5% ≤3 сек |
| Мәртебені өзгерту (audit бар) | 520 | ≥99,5% ≤2 сек | ≥99% ≤3 сек |
| Тапсырысты іздеу (нәтиже көрсетілді) | 1 040 | ≥99% ≤3 сек | ≥98% ≤4 сек |

26 жұмыс күні × 12 сағат = **312 сағ/ай** (бекітілмеген кесте). Пайдаланушыға қолжетімділік SLO 99,5%, SLA 99%; SLO error budget = 312×0,5% = **1,56 сағ = 93,6 минут**; SLA = **187,2 минут**. Жоспарлы үзілістер де саналады.

Операциялар үшін SLO бойынша бүтін сәтсіздік шектері: сақтау **2** / ай, статус **2** / ай, іздеу **10** / ай. Нақты көлемге қарап ай сайын есептеу қайта жүргізіледі.

**50% шек (46,8 минут):** PM жаңа функционалды кідіртіп, инцидент пен түзету шарасын тіркейді; backend логтар мен backup тексереді.

**100% шек (93,6 минут):** жаңа релиз тоқтатылады; RCA, қалпына келтіру және қайта тестілеу басымдыққа өтеді.

Деректердің жариялануы/жоғалуы немесе RBAC бұзылуы P1 ретінде бюджет шегін күтпей өңделеді. Ақшалай айыппұлдар не uptime кепілдіктері келісілмеген.
