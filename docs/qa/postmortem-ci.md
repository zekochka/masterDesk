# ЛЗ 11 — Blameless postmortem

**Оқиға:** MasterDesk GitHub Actions workflow-ының PR/push кезінде іске қосылмауы. **Түрі:** жеткізу тізбегіндегі ақау, пайдаланушы-facing сервис апаты емес. **Күйі:** бұрынғы талқылауда workflow файлының түбірдегі `.github/workflows/` каталогынан ізделгені және қате орыннан `git add` орындалғаны байқалды; нақты GitHub логтары мен минуттық уақыттар ұсынылмаған. Сондықтан төменгі минуттар — талдауға арналған модель.

## Хронология (T+ минут, оқулық реконструкция)
| Уақыт | Оқиға |
|---|---|
| T+00 | PR/өзгеріс жіберіледі; команда GitHub Actions тексеруін күтеді |
| T+03 | Actions бөлімінде күтілген job көрінбейді |
| T+12 | Frontend каталогынан `.github/workflows/frontend-ci.yml` файлын add ету әрекеті `pathspec did not match` қатесін береді |
| T+26 | Workflow орны, түбірлік жұмыс каталоги және триггер шарттары қайта қаралады |
| T+35 | Workflow дұрыс жолға қойылып/коммиттеу тәртібі нақтыланып, қайта жіберу жоспарланады |
| T+41 | Демонстрациялық талдау аяқталады; нақты CI success сілтемесі бөлек дәлелденуі тиіс |

## Әсері
- Өнімдегі нақты пайдаланушылар: **0 (CI конфигурациясы; production релизі көрсетілмеген)**.
- Істен шыққан клиент операциялары: **0 деп бағаланады, бірақ журналмен расталмаған**.
- Delivery тәуекелі: кемінде бір өзгеріс автоматты тексерудің іске қосылғанын дәлелдей алмады.
- 41 минут — **модельдік T аралығы**, өлшенген MTTR емес.

## Қатысты жүйелік факторлар (адамды кінәламау)
1. Workflows GitHub репозиторийінің түбіріндегі `.github/workflows/` каталогынан ғана анықталады; frontend каталогының ағымдағы орны түсініксіз болған.
2. Жаңа workflow бар-жоғын және оның trigger-ін CI міндеттемесіне дейін автоматты тексеру қадамы жоқ.
3. PR қабылдау кезінде «required checks» және workflow run сілтемесін тексеру чек-листі жеткіліксіз.

## Жақсы жұмыс істеген бөліктер
- Терминал нақты `pathspec did not match` хабарламасын берді — бұл қате жолды тексеруге көмектесті.
- PR merge жасалмай тұрып тексерудің жоқтығы байқалды; ол QA қақпасының маңызды екенін көрсетті.
- GitHub Actions және branch protection ЛЗ 10 аясында жоспарланғандықтан, мәселе үшін иелер анық.
