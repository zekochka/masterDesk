# ЛЗ 11 — Тестілеу стратегиясы (MasterDesk)

**Мәртебе:** тестілеу жоспары, 10.11.2026. Нәтижелер нақты іске қосу журналымен расталмайынша тест орындалды деп есептелмейді. TechPoint атынан бекіту алынбаған.

## Жоба және шекара
MasterDesk — TechPoint сервис орталығына арналған жөндеу өтінімдерін басқару жүйесі. Амир — PM/Angular; Ханкелді — ASP.NET Core/PostgreSQL. Қазір Angular демо-нұсқасында басты бет, дүкен, өтінімдер, баптаулар және жергілікті дерек сақтау бар. Серверлік RBAC, орталықтандырылған БД, аудит және API интеграциясы дайын деп қабылданбайды.

## Тестілеу деңгейлері
| Деңгей | Жоспарлы үлесі | Нені қамтиды | Құрал | Іске қосу |
|---|---:|---|---|---|
| Unit | 45% | Форма логикасы, сүзгі, күй басқару | Angular test runner / xUnit | Әр PR |
| Integration | 25% | Angular–API–PostgreSQL, құқықтар, статус тарихы | xUnit, Bruno | API дайын болғанда, әр PR |
| E2E / smoke | 15% | Тіркелу → кіру → өтінім → тізім | Playwright | Стендке әр релизде |
| Load / NFR | 10% | Жауап уақыты, бір мезгілдегі сессия | k6 | Спринт соңында / релиз алдында |
| Manual / UAT | 5% | Пайдаланушыға түсініктілігі, қателер, бейімделу | UAT хаттамасы | Сыртқы топпен қабылдау кезінде |

Үлестер — тест-кейс саны бойынша жоспар; өлшенген test coverage емес.

## Сынақ ортасы
| Орта | Мақсаты | Деректер | Жауапты |
|---|---|---|---|
| Local | UI әзірлеу, unit және smoke | Жасанды, localStorage | Амир |
| Demo / test | UAT және Playwright | Фиктивті жазбалар; 1 000 өтінім қажет болса seed | Амир / Ханкелді |
| Preprod | Толық API, жүктеме, backup restore | Дайындалған жасанды деректер | Ханкелді |
| Production | TechPoint нақты жұмысы | Тек рұқсат етілген деректер | Ресми қабылдаудан кейін анықталады |

**Құпиялылық қағидасы:** нақты клиент аты-жөні, телефоны, ЖСН, құпиясөзі және төлем деректері тест ортасына енгізілмейді. `scripts/generate_test_data.py` бекітілген `seed=11011` арқылы қайталанатын, тек «TEST» белгілері бар 1000 жазба шығарады. Бұл деректерді қолданбаның API келісіміне сәйкестендіру қажет.

## Кіру, шығу критерийлері және quality gates
- PR: өзгеріс шолудан өтеді; npm lint/test/build жасыл; құпия дерек жоқ; өзгерген модуль бойынша кемінде бір тексеру.
- Demo UAT: сайт ашылады, 12 сценарий берілген, сыртқы қатысушы нұсқаулықсыз орындайды.
- MVP қабылдау: барлық P0/P1 ақаулар жабылған, серверлік қауіпсіздік UAT-10 бойынша расталған, міндетті UAT сценарийлері өтіп, тәуелсіз қатысушы қол қояды.
- Өндірістік енгізу: NFR-01/02/03/04/07/09/10 хаттамалары тіркелген; тек localStorage демосы өндіріс деп саналмайды.

## Ақауларды басқару
| Басымдық | Мысал | Ішкі мақсатты мерзім | Қабылдауға әсер |
|---|---|---|---|
| P0 — blocker | Дерек жоғалту, бөгде жазбаны ашу | 4 сағ ішінде әрекет, 24 сағ ішінде fix/rollback | Қабылдау тоқтайды |
| P1 — high | Өтінім жасалмайды, auth жоқ | 2 жұмыс күні | Қабылдау тоқтайды |
| P2 — medium | Форма қатесі, мобильді орналасу | 5 жұмыс күні | Шартты қабылдау тек жазбаша келісіммен |
| P3 — low | Мәтін/дизайн кемшілігі | 10 жұмыс күні | Бэклогқа өткізуге болады |

Мерзімдер оқу жобасына арналған ұсыныс, TechPoint-пен бекітілмеген. Баг карточкасында: қайталау қадамдары, күтілетін/нақты, ортасы, дәлел, severity, priority, owner, due date.
