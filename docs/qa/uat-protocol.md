# ЛЗ 11 — UAT сценарийлері және қабылдау хаттамасы

**Жоба:** MasterDesk / TechPoint. **Жауаптылар:** Амир (ұйымдастыру, frontend), Ханкелді (backend). **Сыртқы қатысушы:** келісу қажет. **Күні:** жоспарланған, нақты өткен күні толтырылады. **Ортасы:** Angular demo (localStorage); API сценарийлері тек backend іске қосылғанда.

**Маңызды:** төмендегі «үлгі» нәтижелер — тек оқу үшін жасалған сценарийлік мысал; нақты адам қатысқан UAT нәтижесі емес. Төмендегі кестеде «Нақты мәртебе» бағаны сыртқы тексеру жүргізілгенше «өткізілмеген» болып қалады. TechPoint тарапынан қолтаңба алынған жоқ.

## Үлгі нәтижелерді түсіндіру (нақты тест емес)
12 сценарийдің 7-еуі үлгіде өтті (58,3%), 2-еуі өтпеді (16,7%), 3-еуі backend жетіспегендіктен бұғатталды (25,0%). Бұл пайыздар жоба сапасының өлшенген көрсеткіші емес. Нақты тестілеуде жаңа нәтижелермен алмастырылады.
