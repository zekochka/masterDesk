# MasterDesk — SoW (ЛЗ 8)

**Күйі:** келісілмеген оқу нұсқасы, 20.10.2026. Тапсырыс беруші — TechPoint. Байланыс тұлғасы — Байкенов Оспан; бекіту өкілеті расталған жоқ. Команда: Амир (PM/Angular), Ханкелді (.NET/PostgreSQL).

## Пән және нәтижелер
14 оқу аптасының MVP жоспары бойынша Angular web UI, ASP.NET Core API, PostgreSQL дерекқор сұлбасы, рөлдік тексеру, тапсырыс және мәртебе тарихы, 20 синтетикалық демо жазба, тест хаттамасы мен пайдалану/backup нұсқаулығы ұсынылады. ЛЗ 5 WBS — 290 сағ.

## Кіреді
Клиент, құрылғы, жөндеу тапсырысы, орындаушыға бекіту, статус, жөндеу құны, іздеу, audit және RBAC.

## Кірмейді
Онлайн төлем, 1С/бухгалтерия, қойма жүйесі, SMS, native мобильді қосымша, AI, көп филиалды басқару, өндірістік мониторинг.

## Қабылдау
1. Кодқа GitHub сілтеме, локал/staging демо, тест парағы, белгілі ақаулар тізімі беріледі.
2. Клиент пен құрылғы, тапсырыс, орындаушы, статус, іздеу, HTTP 403 және audit сценарийлері синтетикалық дерекпен тексеріледі.
3. Ұсынылған пікір білдіру мерзімі — 5 жұмыс күні; жауап болмаса автоматты қабылдау жоқ, «қаралуда» деп тіркеледі.
4. Елеулі кемшілік түзетілген соң ғана қайта қаралады. Өндірістік енгізу бөлек шешім талап етеді.

## Change control
CR: ID, өтініш, business негізі, scope/мерзім/құн/тәуекел әсері, қандай функцияның орнына кіретіні, өкілетті бекітушінің шешімі. Мерзімі тұрақты болса, жаңа жұмыс тек шамалас көлемдегі міндетті емес жұмыстың **орнына** кіреді. Security/RBAC/backup қысқартылмайды.

## Тапсырыс беруші тарапынан күтілетіні
Рөл, workflow, сынақ өкілі, кері байланыс, қажет жағдайда дерек өрістері. Ұйым ішінде жауапты тұлға бекітілуі тиіс. Шынайы деректер келісімсіз қолданылмайды.

## Нәтиже құқықтары және шектеулер
TechPoint деректері TechPoint бақылауында; әзірлеу коды мен пайдалану құқықтары бөлек жазбаша келісіледі. Қолданыстағы SLA, қабылдау актісі немесе лицензиялық құқық беру әзірше жоқ.

## Нені міндеттеме деп есептемейміз
Тапсырудан кейінгі 24/7 қолдау, тұрақты доработка, өндірістік миграция, барлық ақау болмайтынына кепілдік және үшінші тарап жүйелері үшін жауапкершілік SoW-қа кірмейді. Бұлар бөлек келісім мен бюджетпен рәсімделеді.
