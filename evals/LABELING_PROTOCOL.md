# Eval жиынтығы және эталонды тексеру хаттамасы

- Файл: `dataset.jsonl`, 40 синтетикалық өтінім. **TechPoint-тың нақты деректері емес**.
- Әр санат: 5 мысалдан, барлығы 8 санат. Қысқаша/аралас тіл/жанама айтылған шағымдар қосылған.
- Әр өріс бойынша салыстыру: `category`, `incident` — дәл теңдік; `device_model` — әріп регистрі мен бос орындарды нормалау арқылы дәл теңдік. `UNKNOWN` — модель белгісіз.
- Бастапқы эталон жауаптары берілген. Оларды **модельге оқыту үшін пайдалануға болмайды**.
- Бірінші орындаушы Амир және екінші орындаушы Ханкелді әрқайсысы тәуелсіз оқып, белгілеуі керек; келіспеген мысалдарды бірге қарап, эталонды бекіту қажет.
- Қазір тәуелсіз екі адамдық растау **орындалған ретінде белгіленбейді**. Расталған соң төмендегі журналды толтыру керек.

| Қадам | Күйі / дәлелі |
|---|---|
| 40 дерек құрастырылды | Иә, `dataset.jsonl` |
| Бастапқы эталондар жазылды | Иә, файлда |
| Амир тәуелсіз тексерді | Әлі расталмаған |
| Ханкелді тәуелсіз тексерді | Әлі расталмаған |
| Даулы жағдайлар шешілді | Әлі расталмаған |
| Qwen-нің raw нәтижелері | Әлі орындалмады |

Мысалдағы `expected` құрамын модель жауаптарынан кейін өзгертуге болмайды. Егер эталон қатесі табылса, dataset жаңа нұсқа ретінде сақталып, барлық алгоритмдер қайта жүргізіледі.
