# MasterDesk — frontend TechPoint

Автономное демонстрационное приложение для учёта ремонта техники. Интерфейс полностью на русском языке; сервер и база данных пока не нужны.

## Запуск

Нужен Node.js `24.15+` или `22.22.3+` и npm. В папке `frontend` выполните:

```bash
npm install
npm start
```

Откройте `http://localhost:4200/`. Для проверки production-сборки:

```bash
npm run build
```

## Страницы и функции

- **Главная:** показатели из текущих заказов, последние поступления, распределение статусов.
- **Заказы:** таблица, поиск по номеру и клиенту, фильтр по статусу, сортировка по дате, создание, просмотр, редактирование, смена статуса и удаление с подтверждением.
- **Клиенты:** поиск, добавление, редактирование, история заказов, удаление при отсутствии связанных заказов.
- **Мастера:** специализация и количество активных заказов; выбор мастера в форме заказа.
- **Настройки:** информация о деморежиме и восстановление исходных данных с подтверждением.

Формы используют валидацию. Действия показывают уведомления; пустые результаты имеют понятное сообщение. На мобильных экранах меню сворачивается, широкие таблицы прокручиваются горизонтально.

## Данные и будущий API

Исходные 12 заказов, 9 клиентов и 4 мастера находятся в `src/app/services/demo-data.ts`. При первом запуске они сохраняются в LocalStorage под ключом `masterdesk-demo-v1`. Изменения сохраняются после обновления страницы; кнопка в настройках возвращает исходный набор.

Компоненты обращаются к `MasterDeskService`. Контракт `MasterDeskDataSource` находится в `src/app/services/data-source.ts`, реализация `LocalStorageDataSource` — в `src/app/core/local-storage-data-source.ts`. Для подключения ASP.NET Core API следует реализовать этот контракт через `HttpClient` и заменить провайдер в `src/app/app.config.ts`; компоненты и модели можно сохранить.
